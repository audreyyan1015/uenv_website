核心能力

让框架、调度与环境各自保持清晰

稳定的公共边界减少重复接入成本，也让单机验证、多机扩展和任务复现使用同一套方法。

统一契约

评测与训练共享任务模型

Bridge 负责框架转换，任务输入、Episode 状态、结果与轨迹采用统一语义。

弹性执行

Worker 注册后按能力调度

Server 通过注册与心跳掌握容量，把任务交给满足环境和资源条件的 Worker。

可复现

环境、结果和轨迹可以追溯

按需结合 Hub 管理环境包，让任务配置、运行结果与执行过程形成可核验链路。
